# Python Terminal-Based Games 🎮

A collection of classic games and programming experiments built with **Python** and designed primarily for terminal/console play.

## 🌐 Project Website

**GitHub Pages:** https://myg-1107.github.io/Python-Terminal-Based-Games/

The website is a visual showcase of the Python projects. GitHub Pages serves the HTML/CSS/JavaScript interface; the actual games remain Python programs and are run locally from a terminal.

## 🎮 Games & Projects

| Project | File | Focus |
|---|---|---|
| 2048 CLI | `2048-cli.py` | Lists, movement, merging, game state |
| Snake | `snake.py` | `curses`, keyboard input, collision logic |
| Pac-Man / MyMan | `myman.py` | Maze navigation, scoring, enemy movement |
| Pac-Man Console | `pacman4console.py` | Terminal rendering and movement |
| Sudoku | `nudoku.py` | Validation, recursion, puzzle logic |
| Game Hub | `tbg.py` | Tic-Tac-Toe, guessing, word chain, Hangman |
| Additional experiments | `play.py`, `bastet.py`, `test.py` | Game/programming experiments |

## ▶️ Run locally

```bash
git clone https://github.com/MYG-1107/Python-Terminal-Based-Games.git
cd Python-Terminal-Based-Games
python tbg.py
```

Other examples:

```bash
python 2048-cli.py
python nudoku.py
python myman.py
python snake.py
```

> Some `curses`-based games have platform-specific terminal requirements. Linux/macOS generally provide native curses support; Windows may require an appropriate curses-compatible package.

## 🧠 What this project demonstrates

- Python functions and modular game logic
- Loops and conditionals
- Lists and nested data structures
- Random number generation
- Input validation
- Score and game-state management
- Terminal UI concepts
- Keyboard-driven interaction
- Basic algorithms and recursion
