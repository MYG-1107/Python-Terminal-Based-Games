WHY THIS PROJECT?

Learning Python through playable systems.

This repository is a practical collection of small games and experiments. Each game is an opportunity to work with control flow, functions, lists, randomness, input validation, terminal interfaces and game-state management.

The GitHub Pages site is a visual project showcase. The actual games remain Python programs designed to run locally from a terminal.

RUN LOCALLY

Try the games in your terminal.

Clone the repository, install Python 3 and launch a game from the project folder.

$ git clone https://github.com/MYG-1107/Python-Terminal-Based-Games.git
$ cd Python-Terminal-Based-Games
$ python tbg.py
